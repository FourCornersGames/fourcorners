Supprimer votre compte Card Game

Card Game (titre provisoire) par Jeux Quatre Coins (Quatre Coins S.E.N.C.) · Dernière mise à jour : 22 novembre 2026

En bref : vous pouvez supprimer votre compte Card Game vous-même, en tout temps, depuis le jeu. Si vous n’avez plus le jeu, écrivez-nous et nous le supprimerons pour vous.

Le supprimer dans le jeu

  1. Ouvrez Card Game et touchez Paramètres.
  2. Touchez Compte.
  3. Touchez Supprimer le compte.
  4. Confirmez avec Google Play Jeux (Android) ou Game Center (iOS).

Le jeu retire votre compte immédiatement. Vos amis ne vous voient plus. Nous supprimons les données restantes de notre base de données dans les 30 jours. Google, notre fournisseur de services, les retire ensuite de ses propres systèmes et copies de sauvegarde dans un délai de 180 jours.

Ou demandez-le-nous par courriel

Si vous n’avez plus le jeu, écrivez à support@fourcornersgames.ca avec l’objet « Supprimer mon compte Card Game ». Indiquez-nous votre code d’ami et votre nom de profil. Voici comment cela se passe :

  1. Si vous ajoutez votre code de suppression, nous supprimons le compte sans attendre. Vous trouvez ce code à usage unique dans le jeu, sous Paramètres → Compte. Notez-le si vous prévoyez de retirer le jeu.
  2. Sans code de suppression, nous marquons le compte « suppression en attente » pendant 14 jours.
  3. Si le propriétaire se connecte pendant ces 14 jours, le jeu demande « Garder votre compte? » Il peut alors annuler la suppression.
  4. Après 14 jours, nous supprimons le compte.
  5. Nous répondons par courriel quand la demande est fermée. Pour protéger les joueurs, la réponse n’indique pas si un compte correspondait. Tout le processus se termine dans les 30 jours.

Nous supprimons l’échange de courriels quand la demande est fermée. Nous ne stockons jamais de courriels dans nos propres données.

Ce qui est supprimé

  • Votre nom de profil et votre avatar.
  • Votre code d’ami, votre liste d’amis, vos demandes d’ami et vos blocages.
  • Vos paramètres de confidentialité et votre dossier de consentement.
  • Votre liste d’adversaires récents.
  • Les signalements que vous avez faits au sujet d’autres joueurs.
  • Votre lien de connexion avec Google Play Jeux ou Game Center.
  • Votre progression de jeu sauvegardée.

Ce qui est conservé, et combien de temps

Les signalements que d’autres joueurs ont faits à votre sujet sont conservés jusqu’à 12 mois, afin que nous puissions contrer les abus. C’est aussi le cas après la suppression du compte signalé. Ils ne contiennent ni adresse courriel ni vrai nom. Nous ne conservons jamais de courriels ni de vrais noms dans nos propres données.

Désinstaller le jeu ne supprime pas votre compte. Les comptes sans connexion pendant 12 mois sont supprimés.

Supprimer certaines données sans fermer votre compte

Vous pouvez vider votre liste d’adversaires récents et votre liste d’amis dans le jeu. Vous pouvez aussi nous demander de supprimer une partie de vos renseignements sans fermer votre compte. Écrivez à support@fourcornersgames.ca, indiquez votre code d’ami et précisez ce que vous voulez retirer. Nous le ferons et vous le confirmerons dans les 30 jours.

Pour tout le reste concernant vos renseignements, consultez notre politique de confidentialité.
